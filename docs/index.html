Why QuickNote?

No accounts, no cloud sync, no friction. Just open a terminal, dump your thoughts, and get back to work.

⚡

Blazingly simple

One command opens the prompt. Multi-line input, Esc+Enter to save, done.

🎨

Terminal-native UI

Built with Rich and prompt_toolkit — figlet banner, panels, and friendly colours.

📅

Daily markdown files

Notes are saved to ~/.quicknote/Notes/Daily/YYYY-MM-DD.md as plain, portable Markdown.

🔌

Works on desktop & Termux

Designed for Linux/macOS terminals and Android/Termux environments alike.

Built-in commands

A tiny vocabulary that covers daily use.

/today /exit /quit Ctrl + D

Get it running

Clone the repo, run the setup script, and add the launcher to your PATH.

git clone https://github.com/staffordlumsden/Quicknote.git
cd Quicknote
./setup.sh
export PATH="$PWD/bin:$PATH"
quicknote

Requirements

  • Python 3
  • rich
  • prompt_toolkit
  • pyfiglet

The setup script installs them automatically into a local virtual environment.
