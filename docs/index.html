The thought arrives. The thought escapes. QuickNote is the net.
One keystroke, zero friction, pure flow — right in your terminal.

Welcome to QuickNote v1.2 A simple interactive CLI for taking daily notes. >
01 why quicknote

Note apps want accounts, sync plans, and your calendar. QuickNote wants nothing but a terminal and a thought worth keeping.

⚡

Capture in seconds

Run quicknote, type, hit Esc+Enter. The thought is saved with a timestamp before you lose it. That's the whole loop.

📅

One file per day

Every note lands in ~/.quicknote/Notes/Daily/YYYY-MM-DD.md — today's brain, one file, timestamped line by line.

📝

Pure Markdown

Output is portable, greppable, future-proof Markdown. Your notes belong to you — not a walled garden.

🖥️

Old-school, deliberately

Figlet banner, phosphor panels, terminal-native UX built on rich and prompt_toolkit. Retro is a feature.

📱

Desktop & Termux

Born on a phone. Runs wherever Python 3 runs — macOS, Linux, or Android via Termux.

🔓

Zero lock-in

Plain files, open source, no accounts, no telemetry, no subscription. Fork it and make it yours.

02 typed in the terminal, kept as markdown

What you see is a CLI. What you keep is clean Markdown that plays nicely with Obsidian, VS Code, grep, or paper.

●●●you type
> call the registrar re: unit outlines > **exam period:** 10–21 Nov — draft questions > remember: *marking meeting Thursday* (Esc + Enter)
→
●●●2026-09-28.md
# ── saved ── - 07:52 call the registrar re: unit outlines - 07:53 **exam period:** 10–21 Nov — draft questions - 07:54 remember: *marking meeting Thursday*
03 the whole manual

Four commands. That's the entire vocabulary between you and your notes.

/todayPrint today's note file right back at you, in a glowing cyan panel.
/exit  ·  /quitSay goodbye. The banner waves back (in green).
Ctrl+DThe classic. Exits with dignity.
anything elseBecomes a timestamped Markdown note. Yes, even multi-line. Especially multi-line.
04 install

Sixty seconds from clone to your first note. The setup script builds a local venv and a launcher.

●●●bash
$ git clone https://github.com/staffordlumsden/Quicknote.git $ cd Quicknote $ ./setup.sh 🚀 venv created · deps installed · launcher ready $ export PATH="$PWD/bin:$PATH" $ quicknote # ← your first note starts here
